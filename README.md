
# SplitEasy – Expense Management System

SplitEasy is a **Spring Boot-based expense management application** that helps users create groups, manage shared expenses, and split expenses among participants.

## Features

* User registration and login
* JWT-based authentication and authorization
* Create and manage groups
* Create and manage expenses
* Add or remove users from expenses
* Automatic expense share calculation
* Custom exception handling

## Technologies Used

* Java
* Spring Boot
* Spring Security
* JWT
* Spring Data JPA / Hibernate
* MySQL
* REST APIs
* Maven
